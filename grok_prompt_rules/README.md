# Grok official prompting sources

Downloaded on 2026-11-05 from https://docs.x.ai.

- `official-manual.md`: readable combined manual of six official guides.
- `snapshots/`: original downloaded Markdown.
- `sources.json`, `sections.json`: URLs, headings, source hashes and full section text.
- `rules.json`: scoped recommendations with source provenance.
- `coverage.json`: scope and exclusions.
- `llms.txt`: official documentation index.

This is a finite source corpus, not every recommendation on the entire xAI website. Multi-agent recommendations are reference-only. API configuration rules are kept separate from generated prompt text. The generator model is unchanged by For Grok.
