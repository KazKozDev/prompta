# Базовые линии eval

Здесь лежат отчёты, с которыми ночной прогон (`.github/workflows/eval-nightly.yml`) сравнивает свежий
результат: `catalog.json`, `claude.json` и т.д. — по одному на цель.

- Создаются и обновляются только живым прогоном того же провайдера и модели, что в CI:
  вручную запустите workflow с `update_baseline = true` или локально
  `node eval/regress.ts --current report.json --baseline eval/baselines/<цель>.json --update`.
- Обновляйте базовую линию осознанно: после улучшения промптов или смены модели/судьи, а не чтобы
  «погасить» красный прогон.
- В отчёте записаны `promptVersions` и `judgeVersion`: по ним видно, какой версией промптов получены баллы.
